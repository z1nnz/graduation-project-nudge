# Nudge Avatar Parts

`assets/avatar_parts/` 是美術素材工作區，用來放原始分層素材、提示詞、素材清單與後續美術交付檔。

App 實際讀取的透明 PNG 目前仍輸出到 `assets/avatar/`，因為 `AvatarPreview` 的正式路徑已經接好：

- `assets/avatar/base/`
- `assets/avatar/faces/`
- `assets/avatar/hair_back/`
- `assets/avatar/hair_front/`
- `assets/avatar/eyes/`
- `assets/avatar/eyebrows/`
- `assets/avatar/mouths/`
- `assets/avatar/outfits/`
- `assets/avatar/accessories/`
- `assets/avatar/backgrounds/`

## Canvas

- Size: `512 x 768 px`
- Format: transparent PNG for runtime
- All parts must keep the full canvas size, even if the visible object is small.
- Do not crop individual parts, otherwise layers will not align.
- Character anchor: center x `256`; feet baseline around y `705`.

## Runtime Naming

```text
base/body_skin_{skinIndex}.png
faces/face_{faceIndex}_skin_{skinIndex}.png
hair_back/hair_{hairIndex}_color_{hairColorIndex}.png
hair_front/hair_{hairIndex}_color_{hairColorIndex}.png
eyes/eyes_{eyeIndex}.png
eyebrows/eyebrows_{eyebrowIndex}.png
mouths/mouth_{mouthIndex}.png
outfits/outfit_{outfitIndex}_color_{outfitColorIndex}.png
accessories/accessory_{accessoryIndex}.png
backgrounds/background_{backgroundIndex}.png
```

## Layer Order

1. background
2. hair_back
3. base
4. face
5. outfit
6. eyes
7. eyebrows
8. mouth
9. hair_front
10. accessory

## Current Seed Pack

The first seed pack is generated by `tool/generate_avatar_seed_assets.swift`. It is intentionally simple and original, so the app has real layered assets while the team prepares higher quality art generated from the prompt file.
