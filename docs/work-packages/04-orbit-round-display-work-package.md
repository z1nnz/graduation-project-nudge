# 04｜Nudge Orbit 圓形螢幕工作包

## 負責成果

使用已購買的 XIAO ESP32S3 與圓形螢幕，完成一台可獨立、離線、反覆展示的
穿戴型 Nudge 原型。重點是圓形資訊設計與貼身提醒，不需要做電池、錶帶或真正
全天候穿戴。

## 使用者理解

評審看見 Orbit 後，應能在 30 秒內回答：

- 這是一個貼近個人的自律夥伴。
- 它不是縮小版手機，而是一次只顯示一個重要訊息。
- 專注完成後，角色會給出立即回應。

## P0-A 必要畫面

P0-A 只要求 O1 Watch Home、O3 Focus、O5 Complete 自動循環；O0 Boot 可簡單顯示
標誌。其餘 O2、O4、O6、O7 屬於 P0-B 完整故事。

## P0-B 完整畫面

### O0｜Boot

- 中央：Nudge 葉片／角色符號。
- 下方：`ORBIT`。
- 1.5 秒淡入或縮放，不使用複雜粒子。

### O1｜Watch Home

- 上方弧形：現在時間或固定 Demo 時間。
- 中央：角色臉部／芽苗圖形。
- 下方：`SCORE 82`、小型 `DEMO`。
- 不在 240×240 圓屏塞任務清單。

### O2｜Ready

- 中央文字：`FOCUS?`
- 外圈：呼吸光環。
- 底部：`25 MIN`
- 既有觸控／按鍵可開始；否則 3 秒後自動開始。

### O3｜Focus

- 外圈：順時針進度環。
- 中央：大字倒數 `24:18` 或展示倒數。
- 小字：`PROJECT`
- 進度動畫必須平滑，不用每幀重繪整個背景造成閃爍。

### O4｜Encouragement

- 角色抬頭或亮起。
- 短句：`KEEP GOING` 或已驗證可顯示的短中文。
- 小型房間圖示與 `3 ACTIVE`。
- 5 秒後回到 Focus 或進入 Complete。

### O5｜Complete

- 中央勾選與角色開心狀態。
- 外圈由主色轉成完成綠。
- 顯示 `DONE` 與 `25 MIN`。

### O6｜Growth

- 角色從小芽切到展葉姿態。
- `DEMO XP +10`
- `LEVEL 7`
- 這是原型回饋，不呼叫正式 Cloud reward。

### O7｜Summary

- `2 FOCUS`
- `50 MIN`
- `TODAY`
- 停留或回到 Home。

## 圓形版面規則

- 重要內容放在中央直徑約 70% 的安全區。
- 四角不存在，不把矩形版面直接裁成圓形。
- 外圈只負責進度、狀態或呼吸動畫。
- 每幕最多一個主數字、兩行短標籤。
- 最小字在實機 30–50 公分距離必須可讀。
- 避免純白滿屏；使用深色背景降低刺眼與白屏錯覺。

## 開發切片

### ORB-01｜恢復最小顯示基線

1. 只接 XIAO 與圓形螢幕。
2. 燒錄純紅、綠、藍、黑、白輪播。
3. 確認整個圓面都變色，而非只有局部。
4. 保存目前正確插接方向照片。
5. 錄製 10 秒實機影片。

若只有局部變色或白屏，不再按壓玻璃；先核對 XIAO 插接方向、排針是否平行、
driver 與 display rotation。不要把感測器、LED 一起加入除錯。

### ORB-02｜字型與安全區

- 畫中心十字、外圈、四個方向標記。
- 顯示 `NUDGE ORBIT 123`。
- 選定 3 種字級：主數字、標題、標籤。
- 截圖記錄 rotation 與座標。

### ORB-03｜P0-A 靜態三幕

先完成 Home、Focus、Complete，透過固定時間自動切換。三幕在實體圓屏正常顯示
後即可交第一個 P0-A PR，不必等待共用架構。

### ORB-04｜P0-B 靜態 8 幕

先完成每幕靜態畫面，不做動畫。每幕透過 serial `N` 切換，確認沒有記憶體
不足、破圖或上一幕殘影。

### ORB-05｜P0-B 場景引擎

- 接上 `DemoScenario`。
- 自動播放完整流程。
- `restart()` 可從任何幕回 Boot。
- Focus 壓縮成 15–20 秒展示。

### ORB-06｜動畫

只增加三種：

1. Boot 淡入。
2. Focus 外圈進度。
3. Complete 勾選與角色兩幀／三幀動畫。

若動畫造成閃爍或卡頓，退回靜態切換也可通過 P0-A。

### ORB-07｜既有輸入

優先使用已驗證的圓屏觸控或板上按鍵：

- 短按：下一幕／開始。
- 長按：重新開始。

輸入失效時，自動播放仍要工作。

## P1

- 現有光感控制兩到三段亮度。
- 現有蜂鳴器播放開始與完成短音。
- 現有 BLE 接收 `next`／`restart`。
- 可拆式腕帶只作外觀陳列，不需實際佩戴。

- [ ] 全圓顯示正常，沒有只亮局部。

- [ ] 斷網且不開 App 仍可顯示。
- [ ] 交付近拍實機影片、build log 與插接方向照片。

## P0-B 驗收

- [ ] 8 個 Scene 可依序切換。
- [ ] 自動播放 10 輪。
- [ ] 手動 Next 與 Restart 各 10 次。
- [ ] 拔掉所有 P1 模組仍可展示。
- [ ] 交付完整影片與 binary。

## 不做

- 電池、充電、低功耗、睡眠追蹤、心率、步數真實量測。
- 量產錶殼、防水、腕帶耐久或穿戴安全認證。
- 為了做出真正智慧手錶而加入通知中心、電話或複雜選單。
