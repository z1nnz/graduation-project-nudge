# 07｜家庭、團體、自律房與角色成果工作包

## 核心產品循環

Nudge 的特色應是：**每個人自主完成小行動，關係中的共同世界產生可見回應，
但沒有任何人取得監控或控制別人的權力。**

```text
自主行動 → Cloud Receipt → 個人成長
                   ├→ 已同意房間的共同進度
                   ├→ 家庭樹／共同回憶
                   └→ 團體星球／夥伴狀態
```

個人角色 XP、家庭成果 XP、團體成果 XP 必須是不同 ledger/projection，不可因同一
畫面看起來相關就混成一個可重複發獎的數值。

## 切片 A｜自律房整理（P1）

### 房間是什麼

- 長期存在、聚焦單一活動類型的同儕空間。
- 成員各自開始、暫停、完成，不需主持人同時開關。
- room cycle 可每日／每週／期間結算，但 cycle 結束不等於房間結束。
- owner/moderator 管理規則、入會和安全，不控制成員 activity lifecycle。

### 介面建議

- 房間首頁只保留：今日自己的下一步、共同週期進度、目前 resonance、近期同儕
  回應；管理設定放二級頁。
- 健康型房間只顯示 Cloud 驗證 contribution，不提供手動填步數／睡眠。
- 使用固定非診斷 cue 的 Room Resonance，24 小時過期、可立即撤回；不在 signal
  中加入自由文字、精確健康數字或獎勵效果。

## 切片 B｜家庭的誘因（P1）

### 使用價值

- guardian 與 child 共同選擇一個小目標，不是家長派作業。
- 完成後家庭樹長出一個可辨識的小變化；重要 bond event 生成共同回憶。
- 失敗或中斷時提供「重新一起開始」的 recovery ritual，不扣分、不要求補償。

### 必須保留

- 邀請與分享要由接收者同意，可隨時撤回。
- guardian 看趨勢和共同成果，精確健康類別要另有 consent。
- child 自己確認行動；guardian 不得冒充 acknowledgement。
- 關係結束後，已完成且符合政策的共同回憶可讀，但新活動不再流入。

## 切片 C｜團體的誘因（P1）

### 使用價值

- 團體星球將「不同時間、不同活動」累積成共同可見的建設。
- 每週提供少量可選 Quest：例如三天各完成一次最小行動，而不是只比總時數。
- 成員可選擇公開「已參與／持續中／需要鼓勵」等摘要，不公開精確健康明細。
- 達成團體目標解鎖共同視覺或故事，不發放可交易的個人數值優勢。

### 權限

- manager 建立 Quest 和團體設定，但不能替成員加入、填進度或領取成果。
- member 可退出、靜音、撤回分享；排名預設不用原始總量，避免體能／時間差異。
- 移除成員後，current outcome 排除其 stale data；歷史彙總另立不可變契約才做。

## 切片 D｜角色關聯（P1）

### 個人角色

- 回應個人正式 Receipt；顯示進化路徑、當前 XP 與下一個小目標。
- 商城只賣初始階，進化靠 Cloud 驗證的系列 XP。

### 關係夥伴

- 家庭 companion 反映共同照顧與 recovery；團體 companion 反映合作與持續性。
- 不能裝備成個人付費角色，也不能把關係 XP 轉成個人幣值。
- 裝置可顯示當前個人角色與選定關係的安全摘要，但不保留家庭健康明細。

## 切片 E｜量測是否真的有誘因（P1/P2）

先用事件和留存回答問題，再增加更多畫面：

| 假設 | 指標 | 護欄 |
| --- | --- | --- |
| 小行動回饋讓人願意回來 | 首次 Receipt 後 7 日內第二次有效行動率 | 不以推播轟炸取得 |
| 同儕支持減少孤單 | opt-in resonance 發布後收到 acknowledgement 比例 | 不公開精確活動值 |
| 家庭共同目標有幫助 | 雙方同意後完成／恢復率 | guardian 不能代做 |
| 團體世界提升持續性 | 加入 Quest 後跨三日有效參與率 | 不獎勵灌時數 |
| 實體裝置降低啟動摩擦 | 連上裝置後至 started Receipt 的中位時間 | 不忽略失敗／重連 |

埋點事件只記需要的產品狀態與安全識別，不收集自由文字、通知內容或完整健康
數據。實驗開始前先定 success、guardrail 和停止條件。

## 測試

- 角色能力矩陣：guardian/child、manager/member、room owner/member。
- 同一帳號同時屬於多家庭／團體，切換不互相覆蓋。
- 同一 Activity Receipt 不重複產生 personal reward。
- consent 撤回後新 contribution 不再可見，舊資料依 retention policy 處理。
- manager/guardian impersonation、stale membership、removed member 全部 fail closed。
- App 和 Web 讀同一 relationship outcome，狀態與文案一致。

## 非目標

- 不做即時監控孩子或員工。
- 不做公開健康排行榜或人格診斷。
- 不讓 AI 自動替使用者設定強制目標。
- 不用更多功能頁取代清楚的核心循環。
