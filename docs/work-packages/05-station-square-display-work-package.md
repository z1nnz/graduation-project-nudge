# 05｜Nudge Station 方形螢幕工作包

## 負責成果

使用第二個 XIAO ESP32S3 與已購買的方形螢幕，完成一台桌面自律中樞原型。
Station 用較大的矩形空間展示任務、專注、家庭／團體支持與角色世界；不需要
完成永久外殼、焊接或量產電源。

## P0-A 前置：確認螢幕身分

不需要萬用電表，但必須從現有包裝、店家訂單、PCB 印字與晶片字樣確認：

- 商品名稱與連結。
- 解析度。
- driver IC。
- 螢幕介面（例如 SPI）。
- 原廠範例使用的 XIAO 型號與 library。
- XIAO 插接方向或現有線材對照。

把正面、背面、接頭、PCB 印字拍清楚放進 PR。找不到任何資料時，不猜腳位；
先請專題負責人提供購買頁面。

## 評審應理解

- Station 是放在書桌上的專注入口。
- 它比 Orbit 顯示更多脈絡，但仍不取代完整 App。
- 個人自己開始與結束活動；家庭／團體只提供支持，不遠端控制。

## P0-A 必要畫面

P0-A 只要求 S1 Desk Home、S3 Focus、S5 Complete 自動循環；S0 Boot 可簡單顯示
標誌。其餘 S2、S4、S6、S7 屬於 P0-B 完整故事。

## P0-B 完整畫面

### S0｜Boot

- Nudge 標誌。
- `STATION`。
- 右下角短 build id，方便辨認燒錄版本。

### S1｜Desk Home

- 左／上：角色與今日狀態。
- 主卡：`NEXT — 完成專題韌體`
- 次卡：`25 MIN FOCUS`
- 角落：`DEMO`

### S2｜Task Select

顯示最多 3 個固定 Demo 任務：

1. 完成專題韌體。
2. 閱讀 25 分鐘。
3. 散步 3000 步。

若旋鈕可用可移動選擇；否則自動選第一項。

### S3｜Focus

- 大型倒數或進度條。
- 任務名稱。
- 角色專注狀態。
- 可選環境光圖示，不顯示未驗證的精確 lux。

### S4｜Support

依序或二選一：

- 自律房：`3/5 前進中`。
- 家庭：`今天也慢慢來，我們都在`。

角落顯示 `DEMO`，並保留「個人自己開始／結束」的圖示或文字。

### S5｜Complete

- `FOCUS COMPLETE`
- `25 MIN`
- 角色完成姿態。
- 可選 LED 完成效果。

### S6｜Character Result

- `小芽 LEVEL 7`
- 新增一片葉子或能量槽。
- `DEMO XP +10`

### S7｜Today Summary

- 完成任務 2/3。
- 專注 50 分鐘。
- 今日自律分數 82。
- 8 秒後回到 Desk Home。

## 方形版面規則

- 主畫面只保留一個視覺焦點與最多三張卡。
- 資訊優先順序：目前行動 > 時間 > 支持 > 角色成果。
- 家庭與團體不顯示私人詳細活動，只顯示鼓勵與 Demo 聚合。
- 文字在桌面 50–80 公分距離可讀。
- 不照搬 Web Dashboard；Station 是快速狀態，不是管理後台。

## 開發切片

### STA-01｜原廠最小範例

- 只接 XIAO 與方形螢幕。
- 使用符合實際型號的原廠範例。
- 顯示整屏紅、綠、藍、黑、白。
- 顯示解析度、rotation 與 `NUDGE STATION`。
- 保存成功接法照片與 library 版本。

### STA-02｜字型與版面格線

- 畫螢幕邊界與 8 px／12 px 安全邊距。
- 顯示三種字級。
- 確認中文；若不穩定，Demo 使用短英文＋圖示。

### STA-03｜P0-A 靜態三幕

先完成 Home、Focus、Complete，透過固定時間自動切換。三幕在實體方屏正常顯示
後即可交第一個 P0-A PR，不必等待 Orbit 或共用 core。

### STA-04｜P0-B 靜態 8 幕

先以 serial `N` 切換，不接感測器或 LED。完成每幕清畫面，避免殘影。

### STA-05｜P0-B 場景引擎

- 接上與 Orbit 相同的 Scene ID。
- 使用 Station 專用 Layout。
- 自動播放可獨立工作。
- Restart 從任何狀態回 Boot。

### STA-06｜現有互動

若已購買且型號明確：

- 旋鈕：選任務、短按確認、長按 Restart。
- 觸控：點選主卡。
- 板上按鍵：Next／Restart。

若沒有，保留自動播放。

### STA-07｜現有周邊

在 P0-A 通過後才逐一加入 LED、光感或蜂鳴器。一次只加一個，每次都重新做 3 次
冷啟動。任何周邊造成黑屏、白屏或重啟，立即關閉該 feature flag。

## P1

- LED 顯示專注進度和完成效果。
- 光感只切換固定的暗／中／亮三段。
- 蜂鳴器只有開始與完成短提示。
- 旋鈕選擇三個固定任務。

## P0-A 驗收

- [ ] 有商品／PCB 身分卡，不猜 driver。
- [ ] 整屏色彩測試正常。
- [ ] 冷啟動 3 次，10 秒內進 Home。
- [ ] Home、Focus、Complete 自動循環 3 次。
- [ ] 斷網、沒有手機仍可顯示。
- [ ] 交付近拍實機影片、build log 與接法照片。

## P0-B 驗收

- [ ] 8 個 Scene 皆可辨認。
- [ ] 自動播放 10 輪。
- [ ] Restart 10 次。
- [ ] 不接 P1 模組仍可展示。
- [ ] 交付完整影片與 binary。

## 不做

- 焊接洞洞板、永久外殼、電池或量產電源。
- 真實環境健康建議或精確感測儀器。
- 正式家庭監控、團體管理後台或健康資料分享。
- 在螢幕型號未確認前複製圓屏 pin 與 driver。
