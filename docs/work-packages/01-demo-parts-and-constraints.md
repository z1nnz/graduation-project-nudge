# 01｜現有零件與限制

## 原則

本工作包不建立新的採購清單。只使用專題組已經收到的零件；不知道是否已購買
的項目一律視為不存在，不得阻擋 P0。

## 已知可用核心

| 裝置 | 必要核心 | P0 使用方式 |
| --- | --- | --- |
| Orbit | 1 個 XIAO ESP32S3、1 片圓形螢幕、USB 資料線 | USB 供電與燒錄，顯示圓形 Demo |
| Station | 1 個 XIAO ESP32S3、1 片方形螢幕、USB 資料線 | USB 供電與燒錄，顯示方形 Demo |

已購買的按鍵、旋鈕、LED、環境光感測器、蜂鳴器或其他感測器都列為 P1。
只有實際拿得到、看得到型號，而且接線已有店家／原廠資料的模組才可以納入。

## 開發前的零件卡

每台裝置建立一張 Markdown 零件卡，附照片，不需要測量儀器：

```md
裝置：Orbit / Station
ESP32 板上印字：
螢幕正面照片：
螢幕背面照片：
螢幕或包裝型號：
店家商品頁或原廠頁：
目前如何連接：
目前已觀察到的畫面：
USB 線可否成功燒錄：
已購買可選周邊：
不確定事項：
```

如果方形螢幕沒有型號，先拍攝 PCB 正反面、排線和所有晶片字樣。此步驟是為了
選正確 driver，不是要求購買電表。

## 可直接使用的條件

- XIAO 與原廠擴充螢幕可依原廠方向插接。
- 店家已焊好的排針不需重新焊接。
- Qwiic／Grove 等有防呆接頭的已購買模組，可依原廠頁串接。
- 已經成功燒錄過的 USB 資料線繼續使用。
- 已經成功出現完整彩色畫面的接法先拍照保存，不因整理線路而改動。

## 不可猜測

- 方形螢幕 driver、解析度、SPI 腳位與背光腳位。
- 不同廠牌螢幕看起來相同就假設程式相同。
- 感測器的 VCC 是 3.3V 或 5V。
- LED 資料線可任意接任何 GPIO。
- 排針有縫隙就用力壓螢幕玻璃。

資料不明時的正確處理是暫停該周邊、保存照片，先完成另一台或自動 Demo。

## 現有零件的分級

| 分級 | 條件 | 處理方式 |
| --- | --- | --- |
| A | 已成功顯示／讀值，型號明確 | 可進 P0 或 P1 |
| B | 型號明確但尚未成功 | 獨立最小程式測試，不接其他周邊 |
| C | 型號或接線不明 | 不接電、不猜測；只記錄照片與來源 |
| D | 需要焊接、電平轉換或額外工具 | 本次 Demo 延後 |

## 不加購規則

組員不得自行把以下項目加入必要採購：

- 萬用電表、示波器、邏輯分析儀。
- 烙鐵、焊錫、洞洞板。
- 鋰電池、充電模組、升降壓模組。
- 新螢幕、新感測器、新 LED。
- 新外殼或昂貴機構件。

如果現有 USB 線或接頭真的損壞，由專題負責人決定是否以等價替換品補充；這是
維持既有設備，不是擴充功能。

## P0 失敗時的降級

- 圓屏觸控失效：改為自動輪播或開發板按鍵。
- 方屏感測器失效：顯示固定 Demo 數值並標示 DEMO。
- LED 失效：保留螢幕上的完成動畫。
- 蜂鳴器失效：不播放聲音。
- BLE 失效：裝置獨立展示。
- App 失效：由裝置按鍵或自動時間軸完成故事。

降級不是作弊；只要簡報清楚說明「目前展示的原型邊界」，就是可驗收的專題 Demo。
