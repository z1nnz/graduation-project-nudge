# 08｜角色與視覺語言工作包

## 目的

讓 Orbit、Station 與 App 看起來屬於同一個 Nudge 世界，而不是兩份工程範例。
這份工作包不新增角色經濟或正式 XP，只定義競賽 Demo 的畫面與回饋語言。

## 核心概念

角色不是裝飾，而是行為狀態的可視化：

| 行為狀態 | 角色狀態 | 使用者感受 |
| --- | --- | --- |
| Home | 安靜待機、輕呼吸 | 有陪伴、不催促 |
| Ready | 抬頭、準備 | 可以自主開始 |
| Focus | 專注、減少動作 | 不干擾 |
| Encouragement | 看向訊息、微亮 | 支持而非監控 |
| Complete | 展葉／開心 | 行動得到回應 |
| Growth | 增加葉片／能量 | 累積有意義 |

## 共用色彩 token

| Token | 建議色 | 用途 |
| --- | --- | --- |
| Background | 深藍黑 | 預設背景 |
| Primary | 藍紫 | Nudge 主色、Focus |
| Ready | 淺紫 | 準備與首頁 |
| Paused | 琥珀 | 暫停，不表示失敗 |
| Complete | 綠色 | 完成 |
| Support | 青色 | 家庭／團體鼓勵 |
| Text | 暖白 | 主要文字 |
| Muted | 灰藍 | 次要標籤 |

實作時轉成裝置實際使用的 RGB565；先在兩台實機上比較，不要求精準色彩管理。

## 共用文案

語氣必須短、尊重自主：

- `準備好了嗎？`
- `慢慢來，也是在前進`
- `你自己決定何時開始`
- `完成 25 分鐘`
- `今天已前進 2 次`
- `家人傳來一句鼓勵`

避免：

- `你落後了`
- `家長正在監看`
- `管理者已替你開始`
- `不完成就失去角色`

如果中文字型尚未穩定，使用：

- `READY`
- `FOCUS`
- `KEEP GOING`
- `DONE`
- `GROW`

搭配簡報中文解說，不要使用亂碼或過小中文字。

## 角色資源

最小角色只需 4–6 張姿態：

1. idle
2. ready
3. focus
4. support
5. complete
6. growth

Orbit 可只顯示臉部／芽苗圖示；Station 可顯示完整角色與小房間。兩台使用同一
角色識別特徵，例如葉片形狀、眼睛與主色。

## 動畫限制

- 每個動畫 0.3–1.2 秒。
- Focus 不做持續大幅動作。
- Complete 最多 2 秒。
- 不使用快速閃爍。
- 低效能時允許 2–4 幀 sprite 或靜態切換。
- 動畫不能阻止 Next／Restart。

## Demo 標記

下列資料若為固定值，畫面角落放小型 `DEMO`：

- 自律分數。
- 團體人數。
- 家庭訊息。
- XP／Level。
- 步數、睡眠或健康數值。

標記不必破壞主畫面，但必須讓展示者能誠實說明。

## 驗收

- [ ] Orbit 與 Station 的主色、角色、完成色一致。
- [ ] 相同 Scene 在兩台有相同意義、不同版面。
- [ ] 角色狀態與行為狀態一一對應。
- [ ] 30–80 公分觀看距離可讀。
- [ ] 固定資料有 `DEMO`。
- [ ] 動畫可關閉，關閉後仍能完整展示。
- [ ] 圖像來源與授權記錄在 PR。

## 不做

- 新的商城、抽卡、稀有度與付費角色。
- 由韌體自行發放正式 XP 或硬幣。
- 因追求高幀率而延誤完整故事。
- 在比賽前重做 App 全部視覺系統。
