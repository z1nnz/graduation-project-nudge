# 06｜既有輸入、LED 與感測器工作包

## 原則

這份是 P1。只有 Orbit 與 Station 的 P0-A 畫面都完成後才開始。只使用已購買、
型號明確、能用現有接頭連接的零件；沒有任何模組是為了通過競賽 Demo 而必買。

## 優先順序

1. 已存在的按鍵／觸控：讓教授能觸發下一幕。
2. 已存在的旋鈕：Station 選任務。
3. 已存在的 LED：把專注與完成變成可見的環境回饋。
4. 已存在的環境光：做三段亮度。
5. 已存在的蜂鳴器：開始／完成短提示。
6. 其他感測器：除非直接支持展示故事，否則不做。

## 周邊介面

所有周邊透過可失敗的 Adapter 啟動：

```cpp
struct OptionalPeripheral {
  virtual bool begin() = 0;
  virtual void update(const DemoFrame& frame) = 0;
  virtual const char* name() const = 0;
  virtual ~OptionalPeripheral() = default;
};
```

`begin()` 回傳 false 時，主程式只輸出 serial 訊息並繼續顯示，不可卡在
無限重試或 fatal error。

## 按鍵／觸控

建議 mapping：

| 動作 | 行為 |
| --- | --- |
| 短按／輕觸 | Next |
| 長按 1.2 秒 | Restart |
| Focus 中短按 | Pause／Resume，可選 |
| 無輸入 5 秒 | Auto Demo |

加入 30–80 ms debounce，避免一次按壓跳兩幕。

## 旋鈕

只用於 Station：

- 左／右：在三個固定 Demo 任務移動。
- 短按：確認並開始。
- 長按：Restart。

旋鈕不存在或初始化失敗時，自動選第一個任務。

## LED

只做三種可辨認效果：

| Scene | LED |
| --- | --- |
| Home／Ready | 低亮度呼吸或固定主色 |
| Focus | 進度由少到多 |
| Complete／Growth | 2 秒完成色後回低亮度 |

限制亮度，不做高速閃爍。LED 失效不影響螢幕。若現有 LED 需要額外尚未購買的
電平轉換或焊接，本次跳過，不自行採購。

## 環境光

不在 Demo 顯示精確 lux，除非已用原廠範例確認。只映射：

- 暗 → 30%。
- 中 → 55%。
- 亮 → 80%。

每秒取樣並平滑，加入遲滯避免亮度抖動。初始化失敗使用固定 55%。

## 蜂鳴器

- Start：一個短高音。
- Pause：一個短低音。
- Complete：兩個很短的上行音。
- 預設低音量。
- 現場可一鍵靜音。

不播放語音、不循環警報、不在評審談話時連續響。

## 其他感測器是否值得加入

同時符合以下條件才納入：

- 已購買且就在現場。
- 有明確型號與原廠範例。
- 不需要焊接或額外轉接工具。
- 一天內能完成。
- 評審看得到它改變畫面。
- 拔掉後 P0-A 仍正常。

例如只有在實際已購買、接法明確且畫面能顯示「離開座位／回到座位」時，距離
感測才有價值；單純顯示原始數值沒有產品意義。

## 測試矩陣

每加一個模組，做：

- [ ] 模組存在：功能正常。
- [ ] 模組拔除：P0-A 正常，自動 Demo 正常。
- [ ] 模組資料異常：不黑屏、不重啟。
- [ ] 冷啟動 3 次。
- [ ] 完整 Demo 3 輪。
- [ ] serial 能看出模組啟用或略過。

## 交付

- 型號與商品／原廠頁。
- 接法照片。
- feature flag 名稱。
- 成功影片。
- 模組拔除後的降級影片。
- 是否納入比賽現場的最後決定。
