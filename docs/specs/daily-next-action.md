# Daily next action — App/Web slice

- Both home surfaces show one personal next step, without controlling another
  family/group member or issuing rewards.
- Recommend unfinished manual fixed tasks by high/medium/low priority, then
  original order. Ignore deadlines in this small daily-action slice.
- Never turn a health/auto-tracked task into a manual completion suggestion.
- Empty list: invite planning; only tracked work pending: show tracking entry;
  all fixed work completed: offer rest rather than pressure to earn more.
- App shows the current companion and opens the existing TasksPage. Web reads
  only the authenticated user's own document, resets on account change, renders
  text safely, and explicitly distinguishes loading, error, guest and cache.
- These cards suggest navigation only. They do not automatically start focus,
  complete tasks, calculate XP, or claim pending activity is Cloud-confirmed.
- Shared JSON fixtures verify the same selection across Dart and JavaScript.
- This slice is not the complete Living Home, journey, PWA or device integration.
