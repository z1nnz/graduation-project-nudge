# 自律 App 角色美術素材生成規格

## 目標

我們正在製作一款以自律、任務、專注、健康與社交互動為核心的 App。角色系統需要像「紙娃娃換裝」或「Mii 風格角色編輯」一樣，可以讓使用者自由更換臉型、髮型、眼睛、嘴巴、衣服、配件與背景。

請生成一套原創、可商用感、風格一致的 2D Q 版角色分層素材，不要模仿或使用任天堂 Mii、Fashion Dreamer 或任何現有 IP 的角色設計。可以參考「可愛、乾淨、社交遊戲感、紙娃娃換裝」的方向，但所有部件必須是原創。

## 美術風格

- 2D Q 版紙娃娃風格
- 角色比例：大頭、小身體，約 2.5 頭身
- 風格乾淨、可愛、溫暖，不要太幼稚
- 線條柔和，邊緣乾淨
- 色彩明亮但不刺眼
- 可以有輕微陰影、高光與立體感
- 適合手機 App 介面中使用
- 角色要比目前簡單幾何人偶更精緻，有表情、有服裝細節、有辨識度

## 輸出規格

- 每個部件都要是透明背景 PNG
- 建議尺寸：512 x 768 px
- 每個部件都必須對齊同一個角色骨架
- 所有部件放在同一個畫布座標中，方便 Flutter 用 Stack 疊圖
- 不要輸出完整角色大合圖，請輸出可分層組合的部件
- 部件之間不能互相遮錯位置
- 髮型、眼睛、嘴巴、衣服、配件都要能單獨疊在身體底圖上

## 角色基礎骨架

請先設計一個標準 Q 版角色底圖，包含：

- 頭部基準位置
- 脖子
- 身體
- 手臂
- 腿
- 鞋子
- 淡淡的地面陰影

角色站姿為正面站立，雙手自然垂放，表情友善。身體不要太方塊，要有圓角、衣服皺褶和自然比例。

## 需要生成的分層部件

### 1. 身體底圖

請生成 1 個角色裸身/基礎身體底圖：

- 不含頭髮
- 不含五官
- 不含衣服主樣式
- 可以有基本膚色、頭部、脖子、手、腿
- 適合作為所有換裝部件的底層

### 2. 臉型

請生成 6 種臉型，每個都要同尺寸、同位置：

1. 圓臉
2. 鵝蛋臉
3. 方圓臉
4. 小臉
5. 柔和臉
6. 俐落臉

### 3. 膚色

請提供 6 種膚色版本：

1. 淺膚色
2. 暖膚色
3. 小麥膚色
4. 深膚色
5. 深棕膚色
6. 粉嫩膚色

如果圖像生成工具無法一次輸出所有膚色，請先輸出中性淺膚色版本，之後再做色票變化。

### 4. 髮型

請生成 8 種髮型，分成「後髮」與「前髮」兩層會更好：

1. 短髮
2. 微捲
3. 瀏海
4. 中分
5. 丸子頭
6. 蓬鬆短髮
7. 側分
8. 波浪長髮

髮型要可愛、有輪廓，不要只是黑色帽子形狀。要有一點高光、髮束、層次。

### 5. 髮色

髮型素材請能套用以下髮色：

1. 黑色
2. 深棕
3. 淺棕
4. 金棕
5. 灰藍
6. 深藍
7. 紫色
8. 粉色

### 6. 眼睛

請生成 6 種眼睛：

1. 圓眼
2. 笑眼
3. 細長眼
4. 大眼
5. 星星眼
6. 溫柔眼

眼睛要有角色感，可以有眼白、瞳孔、高光，但不要太寫實。

### 7. 眉毛

請生成 6 種眉毛：

1. 自然眉
2. 粗眉
3. 上揚眉
4. 平眉
5. 柔眉
6. 俐落眉

### 8. 嘴巴

請生成 6 種嘴巴表情：

1. 微笑
2. 開心
3. 酷臉
4. 小嘴
5. 抿嘴笑
6. 驚喜

表情要適合自律 App，不要太誇張或太搞笑。

### 9. 服裝

請生成 8 種上身服裝，每件都要符合相同身體骨架：

1. T-shirt
2. 帽T
3. 襯衫
4. 外套
5. 背心
6. 制服
7. 運動衫
8. 針織衫

服裝要有領口、袖子、陰影、簡單細節，不要只是單色方塊。

### 10. 配件

請生成 8 種配件：

1. 無配件
2. 閃光特效
3. 耳機
4. 書本
5. 星星
6. 眼鏡
7. 蝴蝶結
8. 小背包

配件要能放在角色正確位置，例如耳機在頭上、眼鏡在臉上、背包在肩膀附近。

### 11. 背景

請生成 8 種角色展示背景，尺寸可以是 512 x 768 px，也可以是圓角卡片背景：

1. 淡紫背景
2. 淡藍背景
3. 淡綠背景
4. 暖橘背景
5. 粉色背景
6. 灰白背景
7. 奶油白背景
8. 晴空藍背景

背景要簡潔，不要搶角色主體。

## 建議給圖像生成工具的 Prompt

請生成一套原創 2D Q 版紙娃娃換裝角色素材，用於手機自律 App。角色是可愛、乾淨、溫暖的 2.5 頭身比例，大頭小身體，正面站姿，雙手自然垂放。風格像精緻的社交換裝遊戲 UI 素材，但不要模仿任何現有 IP 或任天堂 Mii。請使用柔和線條、乾淨邊緣、明亮但不刺眼的配色、輕微陰影和高光。  

請輸出透明背景 PNG 分層素材，每個素材都使用同一個 512x768 畫布、同一個角色骨架座標，可以直接疊圖組合。需要包含角色身體底圖、臉型、髮型、眼睛、眉毛、嘴巴、服裝、配件與展示背景。每個部件都要對齊同一個人物位置，不要輸出完整合成角色而已。

第一批請先生成：

- 1 個基礎身體底圖
- 4 種髮型：短髮、微捲、瀏海、中分
- 4 種眼睛：圓眼、笑眼、細長眼、大眼
- 4 種嘴巴：微笑、開心、酷臉、小嘴
- 4 種服裝：T-shirt、帽T、襯衫、外套
- 4 種配件：閃光、耳機、書本、星星

請保持所有素材風格一致、位置一致、大小一致，適合 Flutter App 使用 Stack 疊圖。

## 負面提示詞

不要生成：

- 寫實人物
- 3D 模型
- 太複雜的背景
- 現有動漫角色
- 任天堂 Mii 原樣
- Fashion Dreamer 或其他遊戲角色原樣
- 有商標、Logo、文字
- 低解析度、模糊、鋸齒邊緣
- 身體比例不一致的部件
- 無法疊圖的完整角色大圖

## 給美術或 AI 的補充說明

這套素材最重要的不是一次畫很多，而是「所有部件能對齊同一個角色骨架」。  
如果只能先做少量素材，請優先做：

1. 基礎身體底圖
2. 4 種髮型
3. 4 種眼睛
4. 4 種嘴巴
5. 4 種衣服

等第一批素材穩定後，再擴充更多髮型、衣服、配件與背景。
