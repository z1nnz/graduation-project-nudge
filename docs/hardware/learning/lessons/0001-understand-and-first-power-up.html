看懂整台機器，再第一次上電

今天的成果不是「全部接完」，而是你能指出每個模組的角色，並在零件到貨後安全點亮 XIAO＋圓屏。

先備：不用會焊接
完成物：第一張驗收照片
停止條件：發熱／異味／電壓不明

1. 「嵌入式」到底是什麼？

一般電腦可以安裝很多軟體；嵌入式系統則把一台小型電腦放進特定產品，持續讀取輸入、執行規則、控制輸出。Nudge 的 ESP32-S3 就是小型電腦：旋鈕與光感是輸入，螢幕、LED、蜂鳴器是輸出，BLE 是與 App 溝通的橋。

輸入：旋鈕／lux／App→ 運算：ESP32 狀態機→ 輸出：畫面／光／聲／事件

專案特色不只是「有一顆螢幕」，而是把抽象的自律狀態變成可摸、可看、可離線保留、回到 App 後可驗證的實體互動。

2. 每個零件負責什麼？

XIAO ESP32-S3大腦。執行 C++ 韌體、BLE、狀態機與斷電保存。
Round Display主要視覺。顯示時間、房間、目標、角色與同步狀態。
I2C Encoder人的輸入。旋轉選房；短按開始／暫停／繼續；長按完成。
VEML7700環境輸入。把光照 lux 轉成平滑且有界的亮度。
WS2813 Stick環境輸出。用十顆 RGB 呈現 ready、active、paused、rest、complete、offline。
Qwiic Buzzer低干擾聲音輸出。短提示音，App 可以靜音。
SN74AHCT125N電氣翻譯員。把 3.3V 資料高準位轉成 5V LED 看得懂的高準位。
Android App＋Cloud身分與信任。App 綁定帳號、寫 durable outbox；Cloud 驗證 DeviceAssignment 與 Ledger。

3. 到貨當天，不要直接全部接起來

  1. 拍照與核對料號。Round Display `104030087`、XIAO `113991114`／普通 ESP32-S3、Encoder `5880`、LED `104020131`、Buzzer `BOB-24474`、VEML7700 `SEN-29211`。
  2. 檢查焊點與方向。排針是否垂直、有無錫橋、USB-C 是否鬆動；不要插電。
  3. 只組 XIAO＋Round Display。依兩板絲印與 USB 開口方向對齊，平均施力插入；此時不要接 LED、Qwiic 或外殼。
  4. 用資料線接 Mac。先接電腦 USB，不接獨立 5V/2A 電源。碰到明顯發熱、焦味或閃爍立即拔線。
  5. 確認序列埠。終端機執行 ls /dev/cu.*，插拔前後多出的項目通常就是 XIAO。
  6. 編譯再上傳。先證明原始碼能編譯；知道正確序列埠後再 upload。

4. 為什麼要一個一個加？

如果六個模組一起接後畫面不亮，原因可能是電源、短路、I2C 位址、GPIO、函式庫或韌體。一次只加一個模組，就能把問題範圍縮成「上一狀態成功，新模組加入後失敗」。這是工程上的控制變因，不是動作慢。

到貨後的完整加入順序
  1. XIAO＋Round Display：顯示色塊、文字、deviceId。
  2. Encoder：I2C scanner 看見 0x36，再測旋轉與按壓。
  3. VEML7700：看見 0x10，再用手遮光觀察 lux，不先控制背光。
  4. Buzzer：看見 0x34，以最低音量播 50–120 ms 短音。
  5. SN74AHCT125N＋WS2813：斷電接線、共地、量短路，再用 10–20% 亮度測單色。
  6. Android BLE：先看 state notify，再測 configure／start／pause／resume／complete。
  7. Cloud：確認 App durable outbox 先收事件，ACK 後裝置 queue 才移除。
  8. 全部通過才量尺寸、印試裝殼與展示殼。

5. 三個安全原則

一、LED 不能由 GPIO 供電。GPIO 是訊號腳，不是電源供應器。WS2813 的 5V 從 5V 電源軌來，資料經 SN74AHCT125N，GND 與 ESP32 共地。

二、斷電才改線。尤其是 5V、GND、AHCT 與 LED；接地先接、拆線最後拆地。可參考 Adafruit NeoPixel 官方接線指南。

三、硬體事件不是獎勵。裝置可以離線記住 activity event，但 App 必須先 durable enqueue，Cloud 再驗證。否則拔線、重送或偽造封包就可能重複加 XP。
