# Mission: Nudge 嵌入式專注裝置

## Why
親手把 Nudge 的 App、Cloud 與桌上型裝置接成一套可展示、可解釋、可除錯的實體系統，而不是只會照接線圖組裝。最終能在專題答辯時說清楚每個零件、每條資料流與每個安全設計的原因。

## Success looks like
- 能從零件名稱判斷它是輸入、運算、輸出、通訊或供電元件
- 能在不上電的前提下檢查 5V、3.3V、GND 與位準轉換接線
- 能自行編譯、燒錄、看序列埠訊息並定位第一個失敗模組
- 能完成 Android BLE → ESP32 → App outbox → Cloud Activity Ledger 的實機驗收
- 能向評審用兩分鐘清楚解釋裝置為何不直接修改 XP 或角色資產

## Constraints
- 單台實機零件、耗材、外殼與合理運費控制在 NT$5,000 內
- 實體零件尚未到貨；先完成軟體、採購、原理與驗收準備
- 第一版使用 USB 5V 桌上供電，不加入鋰電池
- 不要求實體 iPhone 驗收；BLE 實機驗收使用 Android
- 每次只新增一個硬體變因，先裸板驗收再做外殼

## Out of scope
- 自製 PCB、量產安規、電池續航與無線充電
- 相機、麥克風、CO2、IMU 或健康診斷感測器
- 裝置直接寫入獎勵、角色資產或家庭／團體權限資料
