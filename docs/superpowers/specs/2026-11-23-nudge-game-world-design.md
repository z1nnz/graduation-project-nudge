# Nudge 遊戲世界：角色動作、自律房、全 App 風格與 Web 夥伴小鎮

日期：2026-11-23。延續 `2026-11-23-nudge-companion-cabin-design.md`（夥伴小屋）。
決策：@z1nnz 同意四項全部進行，並授權 Claude 決定細節（原話：「你全部都開始製作好了，我相信你。」）。標為「Claude 決定」的項目都屬於這類。

## 為什麼

只有首頁換成小屋後，其他頁面一點進去又回到卡片與儀表板，落差更明顯。自律房尤其像儀表板：聊天擠在房間頁裡，房內人數只是數字。使用者希望角色會依活動做動作（休息睡覺、讀書、運動），而 Web 採用可走動的世界、建築即功能與 NPC 嚮導，讓入口更有互動感。

## 不變的規則

- 金幣、經驗值只認 Cloud 確認的結果；不新增獎勵來源。
- 自律房成員自主開始與結束活動；房主不能代為操作；不新增排行榜競賽。
- 共鳴只能回應對方自願發出的信號（ADR 0018）；不新增自由私訊。
- 家庭、團體的身分與同意規則不變。
- 減少動態設定下，所有角色動畫停止，改顯示靜態姿勢。

## 1. 角色動作（Claude 決定）

- 4 種姿勢：讀書、睡覺、運動、慶祝。每個系列的第一階角色各有一張姿勢圖（6 系列 × 4 = 24 張），由 Codex 影像生成，參考原角色以保持一致，並以 `tool/cabin_art/key_sprites.py` 去背。
- 第二、三階角色暫時用原圖，加上程式畫的道具與動作：讀書時上下輕擺加翻頁光點、睡覺時呼吸縮放加 Zzz 漂浮、運動時彈跳、慶祝時跳躍加星星。全部系列的姿勢圖補齊後即可直接替換。
- 狀態對應：
  - 正在專注（自己或房內成員的 `studying`）→ 讀書；
  - `resting`，或本地時間 22:00–06:00 → 睡覺；
  - 運動房或運動中 → 運動；
  - Cloud 確認新成果 → 慶祝（播放一次後回到原狀態）；
  - 其他 → 待機。
- 元件 `CompanionSprite(profile, pose)` 共用於小屋、自律房與小鎮。

## 2. 自律房改版

- **自習室場景**：房間是像素風的自習室（讀書房），睡眠房與運動房使用對應場景。最多 8 個座位，成員的角色坐在座位上：
  - `studying` → 讀書（運動房為運動）；
  - `resting` → 打瞌睡；
  - `offline` → 空座位，桌上留一盞熄滅的小燈。
  - 超過 8 人時，最後一個座位顯示「+N」。
  - 自己的角色一律在最前排，並以名牌標示「你」。
- **人數的互動感**：成員狀態改變時，角色會出現或離席（淡入、彈跳），房間上方以「現在有 N 人一起專注」的小字搭配燈光亮度呈現，人越多房間越亮。
- **點成員**：顯示名字、狀態與今日時間（沿用現有可見資料）。若對方有發出共鳴信號，再加上三種固定回應按鈕；送出後該角色頭上冒出對應圖示。
- **共同目標**：房間中央的大燈籠依共同進度點亮（3 段），取代進度條。
- **聊天室獨立**：新增 `StudyRoomChatPage`（文字與貼圖，沿用 `addStudyRoomMessage`）。房間頁只留「聊天」按鈕與最新一則訊息預覽和未讀數；未讀以本機最後閱讀時間計算。
- **管理收納**：房主的設定、審核、公告、邀請收進「房間管理」選單；一般成員不會看到。
- 排行榜區塊移到「房間紀錄」分頁，預設不顯示在主畫面。

## 3. App 其他頁面（Claude 決定）

- 共用元件 `lib/theme/game_ui.dart`：
  - `GamePanel`：木框羊皮紙面板；
  - `GameButton`：金色主按鈕與木色次按鈕；
  - `GameTitle`：像素字感的標題列；
  - `GameChip`：狀態標籤；
  - `GameBackground`：黃昏木屋漸層背景。
- 套用順序：任務頁（改名「委託」）→ 角色、圖鑑、商城 → 家庭、團體 → 統計、設定（只換外觀）。不刪任何功能入口。
- 底部導覽改為：小屋、委託、自律房、圖鑑、同伴。

## 4. Web 夥伴小鎮

- **可走動的小鎮地圖**（Canvas）：
  - 電腦用 WASD、方向鍵或點地面移動；手機點哪裡走到哪裡；點建築或走到旁邊按 F 進入。
  - 鏡頭跟隨角色，提供縮放按鈕。
- **建築與功能對應**：

  | 建築 | 功能 |
  |---|---|
  | 你的小屋 | 小屋 |
  | 委託告示板 | 今日任務 |
  | 專注塔 | 自律房 |
  | 家庭庭院 | 家庭 |
  | 團體會館 | 團體 |
  | 紀錄館 | 統計與週報 |
  | 雜貨店 | 商城 |
  | 遊樂園 | 休息小遊戲 |
  | 天文台 | 裝置 |

  每棟建築上方有名牌和一句用途說明，點進去開啟現有的 Web 頁面內容。
- **NPC 嚮導**：導師 NPC 以 RPG 對話框（頭像、步數、空白鍵繼續、Esc 跳過）帶新使用者逛一圈，鏡頭跟著移到每棟建築。
- **等級解鎖區域**：遊樂園第二座設施 Lv5、鎮外花園 Lv10。未解鎖處顯示柵欄與需求等級。
- **其他使用者**：第一版不顯示其他人在鎮上走動（Claude 決定，避免即時位置同步與隱私問題）；專注塔名牌顯示目前正在專注的人數。
- **浮動介面**：左上為身分與等級，右上為工具列（搜尋、通知、設定、說明），左下為時鐘，右下為縮放。
- **休息小遊戲**：在遊樂園中；需要休息券（規則見小屋設計）。第一款「接星星」。
- **素材**：小鎮地圖與建築由 Codex 產生，畫風與小屋一致（黃昏、紫金配色），素材皆為 Nudge 自製。

## 交付順序

1. 角色姿勢與 `CompanionSprite`，接上小屋。
2. 自律房場景、成員互動、聊天室獨立、管理收納。
3. 共用遊戲風格元件與 App 其他頁面、底部導覽。
4. Web 夥伴小鎮（地圖、移動、建築入口、NPC 導覽、等級解鎖、遊樂園與接星星）。

每一項都附截圖與測試，概念圖不當作完成證據。

## 驗收

- 沿用 C、D 包的驗收矩陣：未登入、pending、錯誤、帳號切換、360px、深色、減少動態。
- 自律房：
  - 成員狀態與座位、姿勢對應正確；
  - 沒有共鳴信號時不顯示回應按鈕；
  - 房主管理只對房主顯示；
  - 聊天頁可以送出文字與貼圖，未讀數正確。
- Web 小鎮：
  - 鍵盤與點擊都能移動並進入建築；
  - 未解鎖區域無法進入；
  - 導覽可跳過；
  - 手機寬度可操作。
