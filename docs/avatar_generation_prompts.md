# 自律 App 角色分層素材生成提示詞手冊

這份文件是給 ChatGPT / 圖像生成工具使用的提示詞。  
目標是生成一套可以放進 Flutter App 的「2D 分層換裝素材」。

重要原則：

- 所有圖片都要是透明背景 PNG。
- 所有圖片都要是同一個畫布尺寸：512 x 768 px。
- 所有部件都要對齊同一個角色骨架。
- 不要每次生成不同姿勢、不同角度、不同比例。
- 所有角色都是正面站立，2.5 頭身 Q 版，可愛、乾淨、溫暖。
- 不要模仿任天堂 Mii、Fashion Dreamer、動漫 IP 或任何現有角色。
- 每次只生成「指定部件」，不要生成完整人物大合圖。

## 共用基礎 Prompt

之後每個部件都可以先貼這段，再接各部位提示詞。

```text
請生成一張 2D Q 版紙娃娃換裝 App 素材，透明背景 PNG，512x768 px，正面站立角色骨架座標固定。風格可愛、乾淨、溫暖、精緻，有柔和線條、輕微陰影、高光，但不要太寫實，也不要像任何現有 IP。素材必須能和其他部件疊圖使用，所以請保持角色位置、比例、頭身、五官位置、肩膀位置完全一致。這張圖只輸出我指定的部件，不要輸出完整角色，不要加文字、Logo、商標、背景。
```

## 負面 Prompt

每次生成時都可以一起貼。

```text
不要生成 3D 模型、寫實人物、完整背景、不同姿勢、側臉、半身圖、裁切圖、低解析度、模糊邊緣、鋸齒、文字、商標、任天堂 Mii 原樣、Fashion Dreamer 原樣、任何現有動漫或遊戲角色。不要改變角色骨架比例，不要讓部件偏移位置。
```

## 生成順序建議

先做最小可用素材，再慢慢擴充。

1. 基礎身體 `body_skin_0.png`
2. 臉型 `face_0_skin_0.png`
3. 後髮 `hair_0_color_0.png`
4. 前髮 `hair_0_color_0.png`
5. 眼睛 `eyes_0.png`
6. 眉毛 `eyebrows_0.png`
7. 嘴巴 `mouth_0.png`
8. 衣服 `outfit_0_color_0.png`
9. 配件 `accessory_1.png`
10. 背景 `background_0.png`

先確認第一套能在 App 疊起來，再開始做其他 index。

# 放進 App 的流程

## Step 1：生成圖片

在 ChatGPT 或圖像生成工具中貼：

1. 共用基礎 Prompt
2. 該部件 Prompt
3. 負面 Prompt

請它輸出透明背景 PNG。

## Step 2：確認尺寸與透明背景

每張圖要確認：

- 是 PNG
- 透明背景
- 512 x 768 px
- 沒有被裁切
- 部件位置和其他圖能疊在一起

## Step 3：重新命名

依照本文件命名，例如：

```text
body_skin_0.png
hair_0_color_0.png
eyes_0.png
outfit_0_color_0.png
```

## Step 4：放到對應資料夾

例如：

```text
assets/avatar/base/body_skin_0.png
assets/avatar/hair_front/hair_0_color_0.png
assets/avatar/hair_back/hair_0_color_0.png
assets/avatar/eyes/eyes_0.png
```

## Step 5：重新啟動 App

Flutter 新增 asset 後，建議完整重啟 App，不要只 hot reload。

如果用終端機：

```bash
flutter clean
flutter pub get
flutter run
```

平常開發時，如果只是替換同名圖片，可以先試 hot restart；如果沒有出現，再完整重啟。

## Step 6：檢查畫面

先去「我的穿搭」頁或商城預覽看角色是否變成圖片分層版。  
如果沒有出現，通常是以下原因：

- 檔名錯了
- 放錯資料夾
- 圖片不是 PNG
- 沒有 `body_skin_0.png`
- 沒有完整重啟 App

## 最小測試清單

第一批只要放這幾張：

```text
assets/avatar/base/body_skin_0.png
assets/avatar/faces/face_0_skin_0.png
assets/avatar/hair_back/hair_0_color_0.png
assets/avatar/hair_front/hair_0_color_0.png
assets/avatar/eyes/eyes_0.png
assets/avatar/eyebrows/eyebrows_0.png
assets/avatar/mouths/mouth_0.png
assets/avatar/outfits/outfit_0_color_0.png
```

成功後再慢慢補其他髮型、衣服、配件與背景。
