# 認領、每日回報與 PR 模板

以下都是待填模板，不是已發送紀錄。

## Issue 認領／交換草稿

需求來源：新版 package 09／10（連至固定需求 SHA）。
本輪裝置：Orbit／Station；持有人：待填；是否交換：否／是。
若交換，原持有人／新持有人／雙方同意連結／日期：待填。
今天單一編輯者與檔案：待填；分支與 base main SHA：待填。
成果範圍與優先級：P0-A／P0-B／P1／P2；依賴 PR／暫測 checkout：待填。
交接時以 main 已合併來源為準，未合併依賴不冒充正式完成。

## 每日回報

```md
今天裝置：
目前 Scene：
實機成功：未驗／失敗／通過，列次數與真正 build id
影片：未拍／相對路徑、SHA-256、起訖秒
下一步：
阻塞：開始時間、可重現否、需誰裁決
是否影響 P0-A：
```

超過半天就回報；沒有實測則填未驗，不能填 0/0 通過。

## 韌體／文件 PR

```md
## 這個 PR 完成什麼
- 問題與 resulting behavior：
- 新增／修改檔案：

## 對應任務／Issue
- 固定新版工作包連結：
- Issue：未建立／真正連結，不填虛構編號
- 負責人與單一成果：
- P0-A／P0-B／P1／P2：

## 硬體與證據
- 實際板子／螢幕／是否獨立主控：待驗或真正型號
- 接線／profile hash：未確認或真正版本
- source commit／environment／binary SHA-256／build id：
- 編譯命令、完整 log、warning 審查：
- upload：未做或實際結果（SUCCESS 不算畫面成功）
- 近拍／全程影片：未拍或相對路徑、hash、起訖秒
- 圖像與字型來源／授權：

## 驗證
- 本機實際命令與結果：
- 最新 head SHA 與六個 CI 結果／run 連結：
- App／Web／Cloud／Rules／Ledger／migration 變動：無或具體影響
- 真帳號／私人資料：本 Demo 不使用
- 實機次數與 Gate：未驗或真正結果，host 次數另列

## 降級、風險與回復
- 不開 App、無網路／手機藍牙、P1 不接仍可 P0-A：未驗／真正影片
- 失效時：停止 P1／P2，回已驗收 P0-A；無已驗收版本時明寫無，不稱可上台
- 尚未完成／沒有宣稱：
- 回復：revert 自己的 commit；Git revert 不會回刷已燒錄硬體

## 提交前確認
- base main，已由最新 main 整理差異
- 只加本次檔案，無憑證／操作員絕對路徑／不相關修改
- 六個最新 head CI 全綠後才 Ready 與請 z1nnz 審查
- 作者不合併；缺實機證據不簽硬體通過
```
