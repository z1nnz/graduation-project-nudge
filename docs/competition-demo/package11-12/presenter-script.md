# 三分鐘口頭腳本（待實機排練）

展示者說故事，操作者照看裝置；一人兼任也要先排練。不要求兩台同步，不用未實測手勢，不為口白暫停不存在的功能。
固定人物小樹、角色小芽、25 分鐘／20 秒壓縮、房間支持與 XP 都是 DEMO；這不是健康數值或正式獎勵。

| 口白 | 操作者觀察 | 畫面沒對上時 |
| --- | --- | --- |
| 0:00-0:25：Orbit 放在近身位置陪伴開始，Station 放桌面帶出今天任務。 | 兩台各看到 Home、DEMO 後開場 | 等下一次 Home；不聲稱能固定停住 |
| 0:25-1:10：準備好了嗎？由使用者自己決定開始。25 分鐘在本原型壓為 20 秒，讓評審看到過程。 | 指向 Ready／Focus，教授願意時只給一個已驗動作 | 沒有已驗輸入就自動播放，不連按、不登入配對 |
| 1:10-1:40：支持訊息代表陪伴，不是家長監看或代為開始。 | 指向 Encouragement 與 DEMO | 等下一圈再指，口白不堵在畫面上 |
| 1:40-2:20：完成後角色展葉，累積有可見回應。XP／Level 是固定示意，不是正式核發。 | 真的看到 Complete／Growth／Summary | 沒看到就不勾完成，不用電腦圖充當實物 |
| 2:20-2:45：需要時重新開始，裝置仍能離線展示。 | 只有已驗重設才操作 | 否則等輪播；不要把未知長按說成有效 |
| 2:45-3:00：這是雙裝置實體原型的設計，下一階段才是真實 App／Cloud 資料整合。 | 原型邊界、收尾；不要承諾可停在某幕 | 兩台故障就用已驗實機影片；沒有就明說備援未備妥 |

時間是排練目標，不是實測。先前 package 02 的固定故事見 PR #22；本卡刻意以實際 Scene 對齊，不把紙面圈長或口白時間寫成韌體量測。
上台不從終端機／程式開始，不要求教授接 Wi-Fi、登入或配對。沒有實機或影片時，改說「目前是準備成果，實機待驗」，不說現場正在即時同步。
