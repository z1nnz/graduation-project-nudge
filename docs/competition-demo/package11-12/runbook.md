# 比賽日操作卡（準備版）

實機稍後驗收；不是上台通過證明。

## 前一晚與到場 15 分鐘

### 先看這一條

本卡是準備版：兩台實機、第二塊 Station 主控、接線與影片均未驗。沒有已凍結且已驗收的版本，不能因 CI 通過就勾選。

### 前一晚確認

[ ] 使用已凍結且已驗收的對應 binary；每台冷啟動 3 次、完整 Demo 3 次。

[ ] 兩條已驗證可傳資料的 USB 線；只有原本已有的供電頭／行動電源才帶。

[ ] 筆電保存 source、binary、PlatformIO 環境與實機影片；手機和離線資料夾都有可開啟副本。

[ ] App 未驗就省略；不在前一晚更新 library、driver 或合併新功能。

### 到場後依序做

1. 固定兩台位置，不拉扯線材；分別接 USB，不同時改線。

2. 核對每台 Boot／serial 的 build id、裝置與既有接法。

3. Orbit 自動一輪；Station 自動一輪；各測已驗證的 Restart。

4. 已採用且已排練的 App／BLE 才測；失敗就關手機操作。

5. 看到兩台 Home 時開始口白。輪播沒有暫停指令，不承諾停留或同步。

## 三分鐘口白與四個口令

### 從畫面開始，不從程式開始

0:00-0:25｜兩台各自看見 Home：Orbit 是近身夥伴，Station 是桌面中樞。

0:25-1:10｜指向 Ready／Focus：25 分鐘以 20 秒壓縮展示，是固定 DEMO。

1:10-1:40｜指向支持訊息與群組情境；沒有真人即時資料或監看。

1:40-2:20｜看到 Complete／Growth 才講完成與成長；正式 XP 並未發放。

2:20-2:45｜只有已驗證重設才操作；否則等待下一輪，不連按搶畫面。

2:45-3:00｜指出原型邊界與下一步 App／Cloud 整合，不宣稱已正式同步。

### 教授只需一個動作

願意互動時只給「按一下」或「轉一下」；未驗證輸入就使用自動展示。

不請教授連 Wi-Fi、登入或配對。結尾觀察 Complete／Growth／Summary，不假設可暫停。

### 全隊統一口令

Orbit reset／Station reset：先用已驗證方法；預設 USB 斷電 5 秒再接。長按手勢尚未驗，不當預設。

Offline demo：停止 App／BLE，使用已驗本機輸入或自動輪播。

Video fallback：只播同硬體版本的預錄實機影片；目前尚無這份影片。

## 故障時照這張卡處理

### 一台沒有畫面

不拆線、不壓玻璃。USB 拔下等 5 秒，再依已確認方向插回；只目視檢查鬆動。

仍失敗：用另一台與該台真正實機影片；接法不明就停止，不猜 pin。

### 畫面停住

用已驗證 Restart；無效再 USB 重啟。台上不臨時重燒；只有負責人確認有足夠時間與已驗版本才考慮。

### LED／感測器／蜂鳴器失敗

忽略選配效果、繼續螢幕。不要在台上拔插周邊；需要改接時先斷電。

### App／BLE 失敗

關閉手機控制，說「裝置保留離線展示，手機連動是選配原型」。

不因登入失敗放棄硬體，不在現場新增帳號或 Cloud 流程。

### 兩台都失敗

播放已核對同硬體版本的一鏡到底實機影片，展示外觀並說明現在不是即時運作。

若沒有已驗影片：明說備援未備妥，使用紙本說明；不能把軟體預覽稱為實機影片。

### 現場禁止

不壓螢幕推排針、不帶電拔插訊號線、不臨時換 driver／library／pin。

不展示未排練功能，不把固定 DEMO 數字說成真實即時資料，不臨時採購。
