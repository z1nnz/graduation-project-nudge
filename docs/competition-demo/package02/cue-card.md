# 展示者與操作者操作卡

本卡目前是待排練計畫。只有取得實際版本、可用重設方法與影片後，才能勾選相應實機結果。

## 開始前

- [ ] 兩台都已確認 USB 供電與各自型號、接法；不為展示猜 GPIO 或帶電改線。
- [ ] Orbit 在 Watch Home、Station 在 Desk Home，DEMO 標記可見。
- [ ] 已確認 Demo 不等 Wi-Fi、Firebase、手機、登入或外接感測器。
- [ ] 每台的自動輪播與回 Home 都已看過；操作者知道該台已驗證的重設方法。
- [ ] App 要展示時已開在指定頁；未驗證就省略，不在評審面前登入。
- [ ] 可選輸入／LED 只使用已驗證者；失效時仍可繼續講解。
- [ ] 備援 binary 與影片確實存在且可離線開啟；若沒有，註記「未備妥」。

目前全部待實機確認，不能因本卡存在就勾選。角色：展示者負責口白與計時，
操作者照看兩台與重設；一人兼任時先排練，不要求兩台同時按鍵或同步。

## P0-A：30 秒短版

從 Home 歸零，每台各自 Home 5 秒 → Focus 20 秒 → Complete 5 秒 → Home。
只講三句：兩台的位置不同、25 分鐘壓為 20 秒、完成後有可見回應。固定資料都標 DEMO。
不需要手動輸入、網路、手機或外接周邊；最低影片必須真拍螢幕，不能用本機時間軸輸出代替。

## P0-B：三分鐘主流程提示

| 口白時段 | 操作者觀察／動作 | 時間或畫面不符時 |
| --- | --- | --- |
| 0:00–0:25 | 兩台 Home 可辨識後開始，觀察自動前進 | 不為口白停住畫面；兩台各自的 Home 時差記入排練表 |
| 0:25–1:10 | 指向 Ready／Focus；約 0:56 下一圈再出現 Focus | 沒有可靠輸入就等下一圈，不重複按 |
| 1:10–1:40 | 指向 Support 與 DEMO | 支持卡過快就繼續講，下一輪再指畫面 |
| 1:40–2:20 | 至少拍到 Complete 與 Growth；紙面參考 2:09–2:18 | 尚未看見完成時不能記為通過，也不能直接跳到「已完成」口白 |
| 2:20–2:45 | 重設兩台，再目視確認 Home；紙面目標最遲 2:30 | 只用已驗證 Restart 或板上 RESET；沒驗證就取消此動作、標 P0-B 未通過，回 P0-A 說明 |
| 2:45–3:00 | 說明原型邊界，結束錄影 | 超時或缺鏡頭就重新排練，不剪接成一鏡到底成功 |

紙面模型的 48 秒一圈只是參考。實機有 boot、render、操作與兩台起跑差異；
不把計算值寫成實測時間。完整影片另須看見每台從 Home 到 Complete，再重設回 Home。

## 失敗備援

| 失敗 | 現場處理 | 缺備援時怎麼說 |
| --- | --- | --- |
| 某台卡住 | 熟悉操作者處理該台既有 USB，另一台與口白繼續 | 「這台尚未恢復，先看另一台的使用情境」 |
| 輸入無反應 | 等自動輪播，不在台上拆線 | 「本次使用自動 Demo」 |
| App 無法連線 | 跳過 App 與登入 | 「這次是離線固定資料展示」 |
| LED 不亮 | 指向螢幕完成畫面 | 「LED 是選配，本次不展示燈效」 |
| 白屏 | 台上先用另一台或已有實機影片；熟悉者在備援電腦使用已驗證、同裝置 binary 恢復 | 「目前沒有可用備援影片／版本，這台驗收仍待完成」 |

不依賴臨時燒錄讓口白繼續，且不把 Orbit binary 燒到 Station。檔案或重設方法不明，
先標未備妥；不給猜測 port、不嘗試未知 serial／BLE 指令、不新增採購。
